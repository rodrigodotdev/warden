# ADR-0004 — SQLx as the driver toolkit

**Status:** Accepted · 2026-08-19

## Context

Warden needs asynchronous MySQL and PostgreSQL support, pooling, prepared-statement
bind arguments, TLS, row streaming, and a native Rust ecosystem without C client
libraries.

Compile-time macros such as `query!` are not decisive because agent SQL arrives at
runtime.

## Decision

Use SQLx 0.9.x with `default-features = false`. See `docs/operations.md` section 2.2
for the exact feature set and the rationale for each exclusion.

## Consequences

Agent queries use runtime APIs with bind parameters. Internal static SQL may use
macros when they improve correctness without complicating CI.

SQLx defaults (`any`, `macros`, and `migrate`) must remain explicitly disabled. Two
contradict project decisions, and disabling them turns the rules into compile-time
errors.
