# ADR-0001 — Rust as the implementation language

**Status:** Accepted · 2026-08-19

## Context

Warden is a long-running security gateway that must model security-state
transitions, perform asynchronous I/O against two databases, and ship as a single
binary.

## Decision

Implement Warden in Rust.

## Consequences

Benefits: strong domain modeling; exhaustive enums that force policy review for
every new variant; explicit ownership; mature async infrastructure; a cohesive
MySQL and PostgreSQL ecosystem; and native distribution without a runtime.

Costs: a smaller contributor pool than scripting languages, compile time, and
explicit boxing for async-trait ergonomics (ADR-0013).
